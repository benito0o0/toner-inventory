# 碳粉库存

适合手机与电脑的碳粉库存网页，包含 K 黑色、C 青色、M 洋红色、Y 黄色。

## 开发

使用 Node.js 18 或更新版本，无外部依赖。

```sh
npm start
```

预设端口为 3000，可用 `PORT` 环境变量调整。

```sh
npm test
```

## 使用

- 每种碳粉可加一、加二、减一、减二。库存不足时对应的减少按钮不可用。
- 调整只改变页面上的暂存数量；按「储存变更」才写入浏览器 localStorage。
- 「取消变更」恢复上次储存的数量。
- 第一次使用时，四种库存都是 0。
- 数据仅保存在当前浏览器及网站来源，不会跨设备同步。清除浏览器数据会移除库存。
- 储存失败会保留暂存内容并显示错误；有未储存变更时离开页面会请求浏览器提示。
